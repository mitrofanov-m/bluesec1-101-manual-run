# BlueSec Manual Lab

Учебный веб-интерфейс для ручного расследования задач соревнования
[BlueSec](https://bluesec.team/). Проект помогает пройти одну задачу от исходного
алерта до итогового вердикта и разобраться, как SOC-аналитик исследует процессы,
файлы, сетевые соединения, события реестра и другие артефакты инцидента.

Проект рассчитан прежде всего на людей без опыта в кибербезопасности. Вместо
полностью автономного агента пользователь сам выбирает инструменты и принимает
решение, а встроенный LLM-наставник **SIEMён Петрович** объясняет результаты,
подсказывает следующий шаг и помогает подготовить финальный ответ.

## Возможности

- подключение к рантайму BlueSec по токену участника;
- получение и ручное расследование одной задачи;
- автоматическое построение форм по схеме доступных инструментов;
- отображение отправленных аргументов, результата инструмента и полного ответа среды;
- сохранение всей истории расследования на экране;
- подсказки наставника через локально авторизованный Codex CLI или Responses API;
- подготовка итогового вердикта наставником без автоматической отправки;
- явное завершение или перезапуск учебной сессии.

## Что понадобится

- Python 3.11 или новее;
- [uv](https://docs.astral.sh/uv/);
- токен участника BlueSec с сайта [bluesec.team](https://bluesec.team/);
- один из способов подключения наставника:
  - установленный и авторизованный Codex CLI;
  - совместимый с OpenAI Responses API endpoint, API-ключ и модель.

## Быстрый запуск веб-интерфейса

Перейдите в каталог приложения и установите зависимости:

```bash
cd bluesec1-agent
uv sync
```

Запустите локальный сервер:

```bash
uv run bluesec1-web
```

Откройте в браузере [http://127.0.0.1:8765](http://127.0.0.1:8765).

На стартовом экране:

1. Оставьте endpoint `bluesec.team:443` или укажите адрес нужного рантайма.
2. Введите токен BlueSec и при необходимости название арены.
3. Задайте имя агента, которое будет видно на платформе.
4. Выберите наставника: локальный Codex CLI или OpenAI API.
5. Нажмите **«Получить первую задачу»**.

Токены и API-ключи хранятся только в памяти локального серверного процесса и не
возвращаются браузеру. Сервер слушает только `127.0.0.1`. Чтобы использовать
другой порт, задайте переменную `BLUESEC_WEB_PORT`, например:

```bash
BLUESEC_WEB_PORT=9000 uv run bluesec1-web
```

## Как проходит расследование

После подключения приложение получает одну задачу и показывает исходное
наблюдение вместе с каталогом инструментов, разрешённых рантаймом. Пользователь
выбирает инструмент, заполняет его аргументы и изучает ответ. Каждый вызов
добавляется в хронологию расследования.

Наставник управляется отдельными кнопками:

- **«Дай совет»** — кратко объясняет текущее состояние расследования;
- **«Помоги решить»** — предлагает один новый нетерминальный вызов инструмента;
- **«Помоги закрыть»** — подготавливает аргументы финального вердикта для проверки;
- кнопка **`?`** рядом с результатом — объясняет важные поля простым языком.

Наставник не отправляет финальный вердикт самостоятельно: последнее решение и
его отправка всегда остаются за пользователем.

## Запуск автономного агента

В репозитории также сохранён референсный автономный агент. Для него создайте
локальный файл конфигурации:

```bash
cd bluesec1-agent
cp .env.example .env
```

Укажите в `.env` параметры рантайма и LLM-провайдера:

```dotenv
SCENARIO_RUNTIME_ENDPOINT=bluesec.team:443
SCENARIO_RUNTIME_TOKEN=your-runtime-token
LLM_BASE_URL=https://provider.example/v1
LLM_API_KEY=your-llm-api-key
LLM_DEFAULT_MODEL=provider/model-name
AGENT_NAME=my-agent
```

Затем запустите агента:

```bash
uv sync
uv run --env-file .env bluesec1-agent
```

Агент будет последовательно получать задачи, исследовать их с помощью объявленных
рантаймом инструментов и печатать серверный результат в терминал.

## Проверка проекта

Из каталога `bluesec1-agent` выполните:

```bash
uv run pytest
uv run ruff check .
```

## Структура репозитория

| --- | --- |
| `bluesec1-agent/src/bluesec1_web/` | веб-интерфейс и LLM-наставник |

| `bluesec1-agent/src/bluesec1_client/` | клиент рантайма BlueSec |

| `docs/` | идея проекта и журнал задач |
