# 001 — Рендеринг результата вызова инструмента

**Статус:** ✅ Выполнено

Для каждого `tool_call` нужно извлекать из `observation` поле `last_tool_result` и рендерить его отдельным блоком сразу после отправленных аргументов.

Порядок отображения:

1. **Отправлено** — аргументы вызова инструмента.
2. **Получено** — содержимое `observation.last_tool_result`.
3. **Полный ответ среды** — полный ответ игровой среды без изменений.

Если `last_tool_result` отсутствует, блок «Получено» не отображается.
