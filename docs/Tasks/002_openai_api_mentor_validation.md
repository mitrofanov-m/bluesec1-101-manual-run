# 002 — Проверка наставника через OpenAI API

**Статус:** ⏳ Запланировано

Проверить LLM-наставника в ручном SOC-интерфейсе через OpenAI Responses API. Реализация
подключения уже принимает на стартовом экране `endpoint`, `API key` и `model`, но живую
проверку с расходованием API-кредита выполняем отдельной задачей позже.

## Сценарий проверки

1. Выбрать **OpenAI API** на стартовом экране.
2. Указать endpoint, ключ и небольшую reasoning-модель; оставить reasoning `medium`.
3. На одной тестовой задаче вызвать **«Дай совет»** и проверить, что ответ учитывает последний
   `tool_call`, не выдумывает сущности и написан простым русским языком.
4. Вызвать **«Помоги решить»** и проверить выбор нетерминального инструмента, предзаполнение
   всех обязательных полей и фактический вызов инструмента.
5. Нажать **`?`** у результата и проверить объяснение ИБ-значимых полей.
6. Убедиться, что ключ не появляется в `/api/state`, истории, логах браузера или тексте ошибок.

## Критерии готовности

- Все три действия возвращают валидный структурированный ответ.
- `finish_investigation` не вызывается наставником автоматически.
- Ошибки авторизации, лимита и несовместимой модели показаны без раскрытия ключа.
- Результаты и выбранная модель зафиксированы в этой задаче.
